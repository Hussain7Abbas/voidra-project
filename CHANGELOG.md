# Changelog

## 0.2.0

Preview of the feature-complete desktop app for Apple Silicon macOS. Plan projects with profiles, actions, questions, approvals, releases, a board and searchable decisions. Run Claude Code or Codex through standalone skills with durable ownership/recovery, exact approval guards, commit history and Sync. Undo planning edits, install matching skills with edit protection, and optionally use private, editable OpenRouter suggestions.

This preview adds the Ink & Iris app icon, unsigned DMG installation, public release checksums, optional update notices and the trusted publishing pipeline. Final v1 release verification remains in P17.

## 0.1.0

Initial public voidra format package and validator CLI.
