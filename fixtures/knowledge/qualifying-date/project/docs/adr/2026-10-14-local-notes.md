# Local notes

## Context
Notes must work offline and stay private. This decision is hard to reverse once user data exists and surprising for a project tool without that constraint.

## Alternatives
Cloud storage provides collaboration but needs accounts and connectivity. Local files preserve privacy and offline access.

## Decision
Keep notes local behind the existing repository boundary. Approved in [act-000000](../../.voidra/actions/act-000000/action.md).

## Consequences
Offline saving works; collaboration needs a later migration and a new decision.
