The same Go and Plan skill texts run locally without the desktop. Both read repository instructions, dispatch the installed template's architecture procedure, publish through the active runtime token, and stop at human gates. Planning-only runs never switch to Go mode to continue implementation. No authenticated agent runs in CI.

Use Node 24.13.0+ and the genuine compatible `voidra` CLI. In development, `make skills-link PROJECT=/absolute/project` exposes the installed folders in `.claude/skills` and `.agents/skills`. Invocations are `/voidra-go` or `/voidra-plan` in Claude Code, and `$voidra-go` or `$voidra-plan` in Codex. The runtime returns the exact template path and architecture skill name; for general, the bundled file is `references/templates/general/template.yaml`, not `references/templates/general.yaml`.

Real checks use Haiku and Luna at low effort, with default-model retries after failure. Claude's JSON result exposes canonical model usage; Codex's JSON rollout does not consistently expose the resolved default model ID. Record the actual command and any model-resolution limit instead of guessing an alias. The configured desktop alias `gpt-6.1-sol` was rejected by the CLI backend; the isolated CLI default worked. The account's model-list response advertised `gpt-6-astra` as default, which is not by itself proof of a particular rollout's resolved model.

Claude checks restrict tools to Bash and Read and confine the whole CLI with a native OS profile: writes are denied except inside the canonical temporary fixture parent and `/dev/null`. Each launch proves an inside write succeeds and an outside write fails. P17's native Bash probes refused protected `.git/config` writes despite allowWrite; its inner Bash sandbox is disabled only inside the verified whole-process boundary, retaining dontAsk, isolated project settings and no MCP. Codex uses workspace-write with the temporary parent explicitly added; a normal worktree's protected `.git` is also explicitly added for Bootstrap. Mixed-queue fixtures use separate Git metadata inside that parent. Normal user repositories retain their own agent permission requirements.

Restricted shells may reject heredocs because their temporary-file location is unwritable. Fixture `TMPDIR`, `CLAUDE_CODE_TMPDIR` and zsh `TMPPREFIX` therefore stay inside the same allowed temporary parent. Write private reports with Node or another permitted file-writing tool; do not broaden permissions or move reports into source files. Reports belong in `.voidra/local/`; npm caches stay outside it. The genuine candidate CLI is installed before fixture baselines and checked offline.

Small models can miscopy ownership tokens or infer a wrong template filename. Use the exact returned path/token. Re-read a checkpoint after a typo; never interpret a rejected token as permission to clear a live owner or edit a lock. The runtime preserves the active run and refuses effects. Explicit recovery occurs only after the original owner exits. A stopped result at Review is waiting for a human decision, even if a model's prose calls its work complete.

The recorded P08 matrix includes real planning, approved implementations, Research, Docs, slices, human blockers, planning-only glossary changes and Review rework. Scripted scenarios and committed golden examples cover deterministic app/format behavior; they do not replace these real-agent outputs.

ADR planning and implementation use the same three-part bar: hard to reverse, surprising without context and a real trade-off. Proposals explain each criterion and wait for approval; implementation records context, alternatives and consequences. Preserve existing ADR naming, otherwise use the actual decision date and title. Add settled glossary terms through the action, preserving existing definitions and requesting a decision before changing their meaning. See [decision/document architecture](architecture/knowledge.md) and the generated `fixtures/knowledge/` examples.

Local releases use voidra-release for atomic selection/queueing, then Go for a proposal and exact Review. Planning-only Release runs stop at Review. Accepted Go runs guard version/changelog files, record checks/both reviews, and use the runtime for one commit/local tag and grouped Released updates. Matching tags reconcile; conflicting tags are never moved. Generated examples and scripted desktop checks do not substitute for P12 real-agent evidence.

`voidra-sync` inspects actual outside Git commits, infers source-linked profile values and proposes work without source/Git writes. Confirmed differences create draft Profile changes; repeat revisions reuse proposals. Its standalone script and template references travel with the skill.

The v1.1.0 versioned Actions contract preserves blocked/gated pending requests and selects the first eligible request in global order. Reordering never retries consumed work; legacy queues retain strict first-item semantics. See [queue format](format/queue.md) and [actual V11-P06 checks](verification/v1.1.0-p06.md). Explicit absolute runtime paths plus `--project` and an explicit fixture working directory avoid a small model substituting a stale global skill after a non-following symlink listing.

Workflow task runs additionally dispatch using `taskRunKind`; see the [QA/security contract](architecture/runs.md#workflow-runs-reader-120). Passing owned quality reports can complete these tasks automatically; legacy results retain human review.
