# Adapt the owned storylens dashboard design system

[ADR index](Intro.md) · [Design system](../design-system.md)

D08 and the P02 blueprint authorize adapting Hussain Abbas's own storylens dashboard source into this AGPL project. Verified revision `daee89af2a5a5255b4dbc240a5d81be2b530b488`; source paths are the dashboard MASTER, token stylesheet and required UI components. The dashboard's LICENSE.md names Hussain Abbas and PolyForm Noncommercial 1.0.0.

The owner-authorized copied/adapted portions are released here under AGPL-3.0-or-later, with author attribution retained. This is not permission to reuse someone else's PolyForm code. Independent frontend dependencies retain their own notices in the packaged licenses directory.

We retain Ink & Iris values, Inter and Lucide, control/card radii, focus/motion and native component patterns. Domain-specific storylens features and its lens artwork are not ported. Dialog cleanup, strict prop typing, app errors and controlled state are adapted for Electron and this repository's TypeScript rules.
