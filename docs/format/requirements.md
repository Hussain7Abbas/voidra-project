# Requirements

[Format index](Intro.md) · [Documentation index](../intro.md)

**Location:** `.voidra/actions/<act-id>/requirements.md`

Frontmatter: `action`. Body requires level-2 Goal and Out of scope sections. Approval is stored on action.md, so no plan file includes its own fingerprint.
