# Format 1 specification

[Documentation index](../intro.md) · [Compatibility policy](../compatibility.md)

This is the contract fixed by P01-01. Implementation and verification follow in the remaining P01 stories. All timestamps are ISO strings with timezone; IDs use six lowercase Crockford base32 characters after their prefix. Unknown fields are retained at every object boundary.
