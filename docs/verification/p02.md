## Delivered behavior

The static Next renderer loads through `app://voidra-project/` in an isolated, sandboxed Electron window. Node access, navigation, popups, permissions, remote content and arbitrary IPC are blocked. Zod checks sender/request/response boundaries. Each project has a separate utility process and real SQLite database, with visible reconnection, bounded automatic restarts and explicit retry.

Folder selection, recent-project persistence, missing-folder Locate/Remove, concurrent-open coalescing, focus-existing/open-new windows and second-instance forwarding are implemented. Settings preserve unknown saved fields and system/light/dark preferences. The effective theme is applied before the first document paint. Corrupt settings are preserved and reported rather than silently reset.

Ink & Iris tokens, Inter Variable, Lucide, reduced motion and all seven requested components are ported from storylens. Source revision: `daee89af2a5a5255b4dbc240a5d81be2b530b488`; source paths were clean when inspected:

- `apps/dashboard/src/styles/globals.css`
- `apps/dashboard/src/components/ui/{button,dialog,confirm-dialog,field,toast,spinner,page}.tsx`

The owner-authorized PolyForm-to-AGPL port, utility-process decision and TanStack bridge cache are recorded in [ADRs](../adr/Intro.md). No storylens branding artwork was copied. ## Boundaries and limitations

Only OS chooser results are substituted in e2e; filesystem, IPC, services, SQLite and windows are real. Axe uses legacy mode because Electron cannot create the auxiliary browser target. This omits cross-origin frame scanning; the app has no such frames and CSP blocks them. VoiceOver and full-product usability testing belong to P17. Automated axe success alone does not certify accessibility.

Source-mapped Electron subprocess V8 coverage is collected selectively. Direct Node stripped-TypeScript subprocess coverage has incompatible offsets and is excluded from child collection, while the package's parent/API coverage remains enforced. Graceful utility shutdown flushes coverage. UI has no percentage gate; no production exclusion was added to improve required coverage.

This is an unsigned application directory with Electron's default icon. Icon approval, DMG, updates and signing strategy are P15. P02 does not read `.voidra/` records or run agents; P03 adds the tracer bullet. No real-agent check applies to this phase.
