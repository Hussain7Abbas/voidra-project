## Release selection and history

The shared collector offers only completed, unreleased work and reserves active selections. Creation carries displayed hashes, preserves member bytes, creates a Release at Plan and declares reader 0.2.0. A private token serializes simultaneous selections. The version-6 disposable cache projects release notes, members, tags and candidates without affecting undo tables. App creation and acceptance make no Git/source-version effects.

Structured proposals bind selection, version/tag, all three plan files and release-record metadata/notes. Full Review fingerprints/write guards include the proposal record and selected action files. Changed displayed notes refuse acceptance; changed approved selection is stale. Final status/date bookkeeping preserves the approved proposal. Accepted proposals/notes enter decision search. Legacy forms remain valid.

The Releases screen shows saved notes/work/tags and active actions, with a labeled keyboard selection dialog. Proposal details render at the action. The new mutation participates in persistent undo/redo, including its private token. The first UI run caught the history boundary refusing that token before any shared write; the narrow private-path permission was corrected. Checkbox layout uses the existing choice controls.
