# V11-P08 — Markdown knowledge and documentation workspace

Date: 2026-10-16. Branch: `codex/v1.1.0-task-foundation`. Development candidate: 1.1.0; this phase does not publish a release.

## Delivered behavior

Decision cards render complete sanitized Markdown rather than a truncated source excerpt. Glossary search highlights the complete source without splitting blank paragraphs, preserving fenced code, tables and lists. Source/actor/date/state/revisit controls and read-only permissions remain.

Documentation now opens as a full page with a directory, retained path/query, document back/forward and the existing contained editor action. Source links flush unfinished forms before navigation. Directory and article scroll independently; the directory toggles and uses the shared pointer/keyboard splitter with private project preferences. A narrow center overlays the directory and closes it on selection.

The utility builds its disposable documentation index lazily, outside Tasks startup. Search filters files by visible text and retains their ancestor directories with occurrence counts. The same sanitized-tree traversal drives counts and semantic highlights, including matches across inline formatting. Previous/next match announces position. Literal matching, Unicode lowercase, whitespace and hidden-content policy are documented in the knowledge architecture. Project-qualified query keys prevent cross-project document cache reuse. Watcher document generations refresh results even when the planning snapshot stays unchanged.

The package inventories contained `docs/**/*.md` and root `GLOSSARY.md`; traversal, linked files/folders, unsupported paths, invalid UTF-8 and oversized reads remain refused. Inventory limits are 2,048 entries, 24 nested levels and 8 MiB total, in addition to 256 KiB per document. Directory diagnostics and search remain available for unreadable/missing selected pages.
