# P10 verification

**Status:** In progress. Persistent history, replay, consumption protection, overwrite confirmation and menu/UI integration are implemented; whole-suite and desktop verification remain pending.

## Implementation

App onboarding now selects the grouped-writer mode of the initializer, including private receipts/empty directories left by undo; existing shared files and symlinks still refuse replacement. Incomplete initialization receipts remain recoverable before metadata exists. Default CLI intake retains atomic folder creation.

The project utility wraps every app editing command through one `UndoHistory.perform` entry point. The bridge's exhaustive `workspaceEdits` classification rejects unclassified future commands at typecheck, and the routing test restricts unlogged commands to reads, Git operations/recovery and history replay. Existing shared helper writes are observed under the grouped writer lock; agent/CLI edits outside the root-scoped asynchronous context remain independent. Public mutation helpers in the workspace are private implementation details of that routed boundary.

SQLite stores operation labels/times, baseline run identities, changed path references and deduplicated SHA-256 bodies. History tables survive index schema changes. Prepared operations and pending replay IDs reconcile against durable private writer receipts after restart, including completing or rolling back an interrupted original edit. Invalid history clears only history tables and displays a notice; source files and index tables survive. The [history ADR](../adr/2026-10-13-undo-history.md) records the delegated limit decision: 100 operations and 32 MiB of distinct snapshot payloads per project.

Replay restores exact UTF-8 bytes through the same writer, including atomic promotions and profile edits that create draft actions. Undo initialization may restore a wholly absent shared project; the bounded writer option still rejects a partial project and persists its recovery policy in the receipt. Outside modifications require confirmation tied to current hashes, and a stale confirmation is refused. Cancel writes nothing. Replay refuses deleting a changed outside file and identifies stage advancement outside the edit.

Persistent run consumption is checked against the edit's baseline run identities and affected record paths/IDs, including queue action IDs, ideas, profile blocks and question IDs. It blocks before implementation begins, remains effective after interruption/lock removal and is rechecked under the writer lock. Git commits are outside history; replay changes planning working files rather than rewriting Git history.

The top bar exposes labeled Undo/Redo controls and overwrite confirmation. Native Edit menu labels describe the current operation; Cmd-Z and Shift-Cmd-Z dispatch project history outside text fields. Text fields retain native text undo via a narrow validated main-process command. Menu state belongs to the focused project window and follows service refreshes.
