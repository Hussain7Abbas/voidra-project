## Delivered

The project utility validates planning files and builds a disposable SQLite action/run index. Missing, corrupt and obsolete indexes rebuild. Chokidar watches `.voidra/`, debounces stable changes and suppresses duplicate display snapshots. Diagnostics name file, field and line; invalid/newer data opens read-only. Unfinished groups and prepared results retain the last complete index.

The desktop creates minimal planning data and Docs/chore actions, renders sanitized Markdown, queues actions, copies each agent's command, displays live ownership and provides explicit recovery commands. Human reviews compare exact displayed action/run bytes. Rejection persists feedback for rework; acceptance completes a committed result.

`tools/run-engine` supplies standalone ownership, consumed-record persistence, durable checkpoints, separate-index commits with both trailers and recovery without repeating side effects. Recovery verifies the original owner even if its lock disappeared, rotates the token and preserves outside edits. The two-minute heartbeat threshold warns; it never clears a live owner. The app delegates Git reconciliation to the agent, preserving its planning-only Git-write boundary.

The repository-owned arm64 libproc helper reads PID/start identity at microsecond resolution inside agent sandboxes. The desktop unpacks it outside asar. Runtime/reference generation and the helper's source/flags hash are checked for staleness. Skill metadata, length and relative resources are linted. Unsupported action types produce an explicit run result without code work.

## Limits

P03 supports Docs/chore only and requires an existing local Git repository. Full onboarding, other lifecycles and app skill installation belong to later phases. Locks coordinate cooperating local writers; they do not sandbox hostile filesystem replacement. Private checkpoint reads reject symlink components. Git hooks still run and altered prepared bytes stop recovery. The arm64 helper's source/flags are checked, but binary reproducibility across Apple SDK/compiler versions is not claimed. Linux fallback behavior is outside the macOS v1 target and unverified.

Axe legacy mode has the P02 limitation: no cross-origin frame scan; CSP forbids frames. VoiceOver belongs to P17. Packaging remains unsigned with Electron's default icon until P15.
