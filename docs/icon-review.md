# App icon review

[Documentation index](intro.md) · [Design system](design-system.md) · [P15 plan](../plan/phase-15-packaging-and-updates.md)

Three original vector directions use Ink #202132, light Ink #eeeff6 and dark Iris #b5a8f5. The UI/UX skill's focused icon catalog searches found no matching workflow entry, so these are original geometry rather than an invented catalog match.

![Path, cards and linked plans](assets/icons/directions.png)

- [Path](assets/icons/path.svg): a V made of connected steps, emphasizing the product name and planned progress.
- [Cards](assets/icons/cards.svg): a recognizable plan list with an active next step, but a more generic app silhouette.
- [Linked plans](assets/icons/links.svg): dependency relationships, but easily mistaken for a general connection/copy tool.

**Accepted agent decision under D24, 2026-10-14:** choose Path. The V has a distinctive silhouette and the two colors remain recognizable without text. Review is delegated; no personal user approval is claimed. The approved source is [icon.svg](../apps/desktop/build/icon.svg); macOS PNG/ICNS exports are generated from it by the pinned Sharp tool and iconutil. The production Dock/DMG icon uses these same exports. No external logo, font or bitmap was copied.
