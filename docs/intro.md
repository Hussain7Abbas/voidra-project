# Voidra Project documentation

Voidra is an open-source desktop app for planning and tracking projects built with AI coding agents. Its [vision](../VISION.md) defines the product, the [implementation plan](../plan/main.md) tracks delivery, and the [root instructions](../AGENTS.md) define the development workflow.

Voidra 1.1.1 delivers an agentic coding workspace with a Tasks Kanban board, Actions sidebar, bottom human-decision panel and shared Markdown experience. The [v1.1.0 implementation plan](../plan-v1.1.0/main.md) contains ten phases and nine confirmed clarification answers; both question rounds are resolved. V11-P01 is complete with an initial Tasks view, project package-version selection, explicit migration and guarded Backlog/TODO movement; [verification](verification/v1.1.0-p01.md) records 424 tests and 70 desktop workflows. V11-P02 is complete with shared safe GFM, active-line/selection source editing and native text history; [verification](verification/v1.1.0-p02.md) records 431 passing quality tests and 73 desktop scenarios across the full run and focused rerun. V11-P03 is complete with Team/Me, selected-client commands and two complete-bundle installers; [verification](verification/v1.1.0-p03.md) records 440 passing quality tests and affected desktop/recovery workflows. V11-P04 is complete with reviewed Normal/Agentic capture and durable private form drafts; [verification](verification/v1.1.0-p04.md) records 451 passing quality tests and affected desktop/recovery checks. V11-P05 is complete with pointer/keyboard Kanban, release filtering and retained task details; [verification](verification/v1.1.0-p05.md) records 453 quality tests and desktop/performance checks. V11-P06 is complete with a global Actions sidebar, exact ordering, dependency repair and safe standalone consumption; [verification](verification/v1.1.0-p06.md) records 461 quality tests, affected desktop workflows and audited actual-client retries. V11-P07 is complete with resizable/toggleable panes, bottom gates/attention and titlebar history; [verification](verification/v1.1.0-p07.md) records 466 quality tests and final panel/native workflows. V11-P08 is complete with full Markdown knowledge views and a searchable Documentation page/directory; [verification](verification/v1.1.0-p08.md) records 469 quality tests and both-theme Electron checks. V11-P09 is complete with Xeploy-guided release drafts and exact Keep/Move choices; [verification](verification/v1.1.0-p09.md) records 475 quality tests, both actual client flows and archived-app checks. Every unfinished data-entry form saves a private local draft on exit and shows one top navigation badge per draft when reopened; fresh task forms start in Agentic, while restored drafts keep their mode. The [draft contract](../plan-v1.1.0/form-drafts.md) tracks this across phases. [Vision section 17](../VISION.md#17-v110-product-direction) records the product changes. V11-P10 completes all ten phases: 483 quality tests, 102 desktop scenarios, both actual client matrices and GitHub/npm/skills publication, including verification of the public downloaded app. [Final evidence](verification/v1.1.0-p10.md) records the performance and manual accessibility limits. The documentation below describes the delivered workspace and retains the original v1 evidence as history.

P00 supplies repository tooling and policies. P01 publishes the format package and CLI; validation and publication are recorded in its evidence. P02 adds the secure desktop shell and its design system. P03–P09 complete the core loop and reach M2; this repository now tracks its own ideas and bugs in `.voidra/`. P10 completes persistent app undo; P11 completes decisions, assumptions and read-only repository docs/glossary. P12 completes releases and Sync with full local/CI and real-agent evidence. P13 completes optional editable AI suggestions; P14 completes offline skill installation and guarded distribution. P15 completes live packaging/publication recovery for preview 0.2.2, and P17 completes v1.0.0 publication, both-agent verification, the user-reported VoiceOver pass and actual downloaded-app verification; M4 is reached. P16 records the future v2 designs without implementing them.
